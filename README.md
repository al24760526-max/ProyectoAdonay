# Sistema de inventarios
Este software permite a una empresa gestionar:
   *Su inventario de productos
   *Los pedidos que realizan los clientes
   *Los detalles del pedido (productos solicitados)
El sistema debe permitir:
   *Registrar productos con su stock.
   *Registrar clientes.
   *Registrar pedidos realizados por cada cliente.
   *Registrar qué productos incluye cada pedido.
   *Actualizar el stock cuando se realice un pedido.
   *Consultar ventas, productos más vendidos, pedidos por cliente
